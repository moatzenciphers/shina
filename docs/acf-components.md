# Общие ACF-компоненты страниц и услуг

## Что обновлено

| Компонент | Изменения |
| --- | --- |
| `hero` | Варианты «Главная» и «Услуга»: обычный заголовок, надпись сверху, фоновое фото, текст CTA и пояснение под ним. Для главной сохраняются рейтинг и заголовок с 24/7. |
| `columns_list` | Новый блок: две колонки списков, пояснение и типовая кнопка калькулятора. |
| `price_table` | Новый блок: основной прайс, группы доплат, примечания, типовая CTA. Источник сумм — опубликованные записи `prices`. |
| `cards_grid` | PHP теперь учитывает поля выбранных услуг и количества записей. Источник карточек — `services`, ссылка внизу — архив услуг. |
| `media_rows` | Добавлена подпись заглушки для ряда без изображения, сохранена композиция Pug. |
| Остальные | `features_grid`, `steps_grid`, `slider_grid`, `map_panel`, `gallery_grid`, `accordion_grid`, `split_form` включены в общий реестр. Их поля, формы CF7, источники записей и JS-хуки сохранены. |

Всего в flexible content `blocks` — 12 макетов. Хедер, футер, попап быстрого вызова, мобильные кнопки и сам калькулятор не являются макетами flexible content.

## Установка обновления

1. Обновите файлы темы из этого изменения, включая `page.php`, `single-services.php`, `inc/components.php`, `template-parts/components.php`, новые компоненты `landing-columns-list.php`, `landing-price-table.php` и общий `js/site.css`. Старый `inc/landing.php` больше не подключается.
2. Через **ACF → Инструменты → Импорт групп полей** импортируйте обновлённый `acf-landing-import.json`. Ключ `group_landing_front_page_flexible`, имя `blocks` и ключи прежних макетов/полей сохранены. Не удаляйте существующую группу перед импортом.
3. Группа «Блоки страниц и услуг» отображается на всех записях типа `page` и `services` (условия OR). Выберите порядок и содержимое блоков для каждой страницы.

Общий вывод подключается из `page.php` для страниц с заполненным `blocks`. Главная и `single-services.php` используют тот же `page.php`. Общая разметка находится в `template-parts/components.php`, функции — в `inc/components.php`. Пустые страницы сохраняют прежний вывод; отдельные пользовательские шаблоны, включая калькулятор, не подменяются. Внешняя обёртка, мобильные действия и форма быстрого вызова создаются общим компонентом. Хедер и футер визуально не менялись; из header.php перенесено только открытие обёртки.

Код не регистрирует flexible-группу через `acf_add_local_field_group`: она редактируется в админке после импорта JSON. Импорт не заполняет контент страниц автоматически и не изменяет уже сохранённые тексты. Старые упоминания калькулятора в полях при необходимости исправьте вручную.

## Заполнение услуг

- В hero выберите вариант **«Услуга»**, задайте заголовок, текст, преимущества, фото и пояснение под кнопкой. Вариант «Главная» оставляет прежний первый экран.
- На записи `services` все кнопки расчёта открывают калькулятор с `?service=слаг-текущей-услуги`, без проверки по фиксированному списку. На обычной странице можно указать произвольный слаг в поле **«Слаг услуги для калькулятора»**.
- Шорткод быстрого вызова задаётся на каждой странице в `quick_call_shortcode`, формы карты и помощи — внутри их макетов. Формы выводятся существующим обработчиком CF7.
- В `columns_list` заполните заголовки колонок и повторители пунктов.
- В `media_rows` можно временно оставить фото пустым и подписать заглушку. Для реального фото используется медиабиблиотека.

## Таблица цен

Сначала импортируйте `acf-prices-import.json`, загрузите цены и опубликуйте нужные записи `prices` (импортёр создаёт их черновиками).

- Выберите цены в поле услуги `services_prices`. Компонент читает только эту связь текущей записи и сохраняет порядок выбранных позиций; поддерживаются ID и объекты WP_Post. Без связи все цены подряд не выводятся.
- В самом макете осталось четыре текстовых поля: `pricing_eyebrow`, `pricing_title`, `pricing_description`, `pricing_group_note`. Выбора услуги, цен, групп и заголовков столбцов в компоненте нет.
- Для `price_type = table` заголовки комплексов берутся из `price_rows.name`, суммы — из `price_rows.value`. Все колонки сохраняются, отсутствующее значение показывается как «—».
- Для `value` выводится обычный столбец стоимости. `rub`, `rub_from`, `rub_per_item`, `percent` задают формат. Проценты в группах доплат получают знак `+`.
- Записи с `price_additional = true` выводятся единственной группой с фиксированным названием «Доплаты». Если таких записей нет, группа и её примечание не выводятся. Остальные записи попадают в основную таблицу.
- Названия позиций и комплексов, значения и форматы берутся из `prices`. Первый столбец называется «Наименование», столбец обычной цены — «Стоимость». Кнопка «Вызвать мастера» и нижнее пояснение стандартные, отдельных полей для них нет.

## Генерация и проверка

```sh
node generate-landing-acf.cjs --write
npm run build
```

`generate-landing-acf.cjs` — источник структуры JSON. Все компоненты используют общий `src/scss/main.scss` и WordPress `js/site.css`, отдельной сборки для страниц услуг нет. При этом обновлении недостающие стили добавлены к существующему `site.css`, сохранив его прежнее содержимое.

Проверены сборка фронтенда, структура JSON и соответствие макетов PHP-компонентам. Проверка в работающей админке и вывод реальных ACF-данных требуют запуска WordPress на целевом сайте.
