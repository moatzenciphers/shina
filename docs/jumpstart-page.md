# Страница запуска двигателя

Локальный предпросмотр: http://localhost:8080/jumpstart.html при запущенном dev-сервере. Сборка создаёт `dist/jumpstart.html`. На WordPress ничего не публиковалось.

Использованы десять готовых блоков, общая шапка и футер. Новых композиций и SCSS нет. Ссылки в меню и карточке главной открывают страницу услуги; её CTA ведут в общий калькулятор без подмены тарифа другой услугой.

## Где редактировать

| Содержимое | Файл |
| --- | --- |
| SEO title/description, H1, оффер и преимущества | `src/pages/data/jumpstart-page.js`: meta, hero, features |
| Данные для вызова, этапы и фото-ряды | Там же: columnsList, steps, mediaRows |
| Таблица запуска, зарядки АКБ и пуска мотоцикла | `src/pages/data/jumpstart-prices.js`, источник `prices-export.json` |
| Вопросы и форма | `src/pages/data/jumpstart-page.js`: faq, form |
| Порядок готовых секций | `src/pages/jumpstart.pug` |

Прайс читает все три позиции, связанные с услугой «Запуск двигателя». Сохранены исходные форматы: начальная цена для запуска двигателя, обычная сумма для зарядки и пуска мотоцикла. За пределами таблицы конкретные суммы не повторяются. Доплаты не придуманы, отдельной группы в исходных данных нет.

## Что уточнить перед публикацией

1. Точный состав начальной цены запуска и условия оплаты, если проблема не решается внешним пуском. Гарантированный запуск и правило «нет результата — бесплатно» в тексте не обещаны.
2. Формат зарядки АКБ: на месте или с передачей батареи, сроки, условия и состав указанной цены. Продолжительность процедуры не придумана.
3. Поддерживаемые автомобили, дизели, гибриды/электромобили и мотоциклы, требования к напряжению и оборудованию. Универсальная поддержка всех типов транспорта не заявлена.
4. Доступ в закрытую машину и другие отдельные работы: не считать их частью услуги без согласования.

Тексты посвящены выезду и помощи при разряде АКБ, а не самостоятельному подключению пускового устройства. Причина отсутствия запуска может быть другой; инструкции по подключению проводов и обещания устранить любую неисправность не добавлялись.

## Фото и отзывы

- Замените `hero.image` на реальное фоновое фото автомобиля и мастера, сохранив место слева для текста. Сейчас используется `jumpstart-placeholder.svg`.
- В `mediaRows.rows[0]` добавьте `image` и `alt` для осмотра АКБ перед запуском.
- В `mediaRows.rows[1]` добавьте фото пускового оборудования/проверки результата. Поле `photo` подписывает заглушку до появления изображения.
- Текущие отзывы временные, общий массив не менялся. Подберите реальные отзывы о запуске автомобиля.

Предложение по наполнению: в существующем `media-rows` показать реальные примеры выездов после стоянки и на парковке, с коротким описанием согласованной работы. Для этого новый блок не нужен. Любые новые композиции сначала согласовываются с владельцем.

## Перенос на WordPress

Перенесите контент в существующие ACF-макеты `blocks`, выберите вариант hero «Услуга». В записи услуги через `services_prices` выберите три опубликованные позиции прайса; все они основные. FAQ выбирается из записей `faq`, отзывы — из `reviews`. Формы подключаются через CF7; Pug-формы остаются прототипами.

Отдельного тарифа запуска в текущем калькуляторе нет. Сохраните открытие общего калькулятора при переносе, пока соответствующий расчёт не добавлен отдельно.

Для окончательного URL сохраните уже существующий адрес услуги, если он есть. Прежний путь карточки проекта — `/uslugi/prikurka-avtomobilya/`; его публикация не проверялась. SEO-поля подготовлены в meta. Canonical и sitemap на WordPress должны соответствовать выбранному адресу.
