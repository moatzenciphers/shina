# Страница правки дисков

Предпросмотр при запущенном dev-сервере: http://localhost:8080/wheels.html. Сборка создаёт `dist/wheels.html`. На WordPress ничего не публиковалось.

Страница использует десять готовых блоков и общую шапку/футер. Новые композиции и SCSS не создавались. Ссылки в меню и каталоге ведут на страницу, CTA открывают общий калькулятор без выбора другого тарифа.

## Где менять

- `src/pages/data/wheels-page.js`: SEO title/description, hero, преимущества, сведения для осмотра, тексты прайса, шаги, фото-ряды, FAQ и форма.
- `src/pages/data/wheels-prices.js`: читает 13 позиций R12–R24, связанных с услугой «Правка дисков», из `prices-export.json`.
- `src/pages/wheels.pug`: порядок готовых секций.

Суммы сохранены из исходного прайса с форматом rub. На странице они указаны только в таблице. Начальная цена карточки главной приведена к минимальному значению из выгрузки.

## Что уточнить перед публикацией

1. Какие диски обслуживаются: литые, штампованные, кованые; ограничения по конструкции, материалу и изготовителю. Прайс по диаметру сам по себе не подтверждает допустимость конкретной работы.
2. Какие операции доступны по адресу, а какие требуют другого формата обслуживания. Наличие станка, конкретная технология, нагрев или сварка не обещаны.
3. Единица тарифа и состав цены: снятие/установка колеса, демонтаж/монтаж шины, балансировка, выезд. Их включение не предполагается автоматически.
4. Условия гарантии, оплаты осмотра и действия при необходимости замены. Универсальный срок гарантии и восстановление любого повреждения не заявлены.

При подготовке текста учтено, что изготовители колёс могут запрещать восстановление повреждённых дисков. Материал не представляет правку, нагрев или сварку как способ вернуть любое изделие в безопасную эксплуатацию. Проверка допустимости должна учитывать конкретный диск и требования его изготовителя.

## Фото и отзывы

- Замените `hero.image`: сейчас используется `wheels-placeholder.svg`. Реальный кадр остаётся фоном на весь первый экран; слева нужно место под текст.
- В `mediaRows.rows[0]` добавьте `image` и `alt` для осмотра повреждения диска.
- Во втором ряду покажите реальную проверку колеса и согласованный результат. Сейчас оба ряда подписаны как заглушки.
- Текущие отзывы временные, общий массив не менялся. До публикации выберите реальные отзывы по услуге.

Предложение без нового блока: в готовом `media-rows` разместить фотографии реальных повреждений с решением мастера — какие действия согласованы и почему. Это полезнее обещания одинакового результата для всех дисков. Для нового типа композиции потребуется отдельное разрешение владельца.

## WordPress

Перенесите данные в существующие ACF-макеты `blocks`, вариант hero — «Услуга». Свяжите опубликованные позиции R12–R24 через `services_prices` записи услуги. Все исходные позиции основные, поэтому отдельной группы «Доплаты» для них нет. Вопросы и отзывы выбираются из `faq`/`reviews`, формы подключаются через CF7.

Калькулятор пока не поддерживает отдельный расчёт правки дисков. Сохраните открытие общего калькулятора на этой странице до внедрения такого расчёта.

Для конечного URL сохраните существующий адрес услуги, если он уже есть. Прежний путь карточки проекта — `/uslugi/pravka-diskov/`; наличие опубликованной страницы по нему не проверялось. SEO-поля подготовлены в meta, canonical и sitemap настраиваются под окончательный URL на WordPress.
