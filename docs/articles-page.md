# Страница статей

- Заполненное состояние: http://localhost:8080/articles.html.
- Вторая страница: http://localhost:8080/articles-page-2.html.
- Пустое состояние: http://localhost:8080/articles-empty.html.

Все варианты используют один `src/pages/articles.pug` и компонент `blocks/articles-grid.pug`. Данные — `data/articles.js`: 12 примерных материалов, шесть на страницу. Пагинация работает обычными ссылками между двумя HTML-страницами, без JS. На первой странице недоступна стрелка назад, на второй — вперёд; текущий номер не ссылка.

Сетка 3/2/1, фото 8:5, общая типографика и палитра, шапка/футер. Изображения взяты из доступных файлов проекта. Названия, даты, рубрики и анонсы демонстрационные. Первая карточка ведёт на подготовленную article.html; остальные пока `#`. Инструкция детальной страницы: docs/article-page.md.

В пустом состоянии нет карточек и пагинации, показаны сообщение и переход к услугам. Вступление написано в будущем времени, без утверждения о наличии публикаций. Состояние вынесено на отдельный URL для просмотра.

На обеих страницах после архива добавлены готовые `columns-list` и `split-form`. Для заполненного архива текст объясняет тематику раздела и различия объёмов обслуживания. Для пустого — описывает уже доступные услуги. Данные обоих текстовых блоков и формы находятся в `data/articles.js`; поля и обработка общей формы не менялись. В прототипе отправка не подключена, при переносе используйте CF7.

Для WordPress подготовлены category-articles.php и single-article.php, ACF-импорт и штатная пагинация. Установка: `docs/wordpress-articles.md`. Pug-примеры не импортируются в базу автоматически.
