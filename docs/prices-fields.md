# ACF-поля записей prices

Импорт: «ACF → Инструменты → Импорт групп полей» → acf-prices-import.json. Группа привязана к типу записи prices; этот тип записи должен быть зарегистрирован с поддержкой заголовка.

| Столбец | Хранение | Поле |
| --- | --- | --- |
| Наименование | Стандартный заголовок WordPress | post_title |
| Услуга | ACF Relationship с одной или несколькими записями services | price_services |
| Тип | Select: value / table | price_type |
| Дополнительная | True/false | price_additional |
| Тип вывода | Select | price_display_type |
| Значение | Number, показывается при price_type = value | price_value |
| Название / Значение | Repeater, показывается при price_type = table | price_rows |

В повторителе каждая строка содержит name (текст) и value (число). Несколько услуг выбираются потому, что в Excel одна позиция может относиться сразу к нескольким услугам. Relationship возвращает массив ID.

## Варианты селектов

- price_type: value — «Значение», table — «Таблица».
- price_display_type: rub — «Рубли», rub_from — «Рубли от», rub_per_item — «Рубли за шт», percent — «Проценты».

В числовых полях хранится только число: 20 для 20%, 4800 для 4 800 ₽. Единицы определяет тип вывода. Признак «Дополнительная» независим от остальных полей и сохраняется как задано владельцем.

Столбцы «Название[0] / Значение[0]», «Название[1] / Значение[1]» и следующие пары Excel соответствуют строкам одного повторителя, без фиксированного количества вариантов.

Этот файл задаёт структуру админки. Записи и числовые цены из Excel не загружаются при импорте группы ACF. Подключение нового прайса к фронтенду выполняется отдельным шагом.

## Экспорт Excel

Из корня проекта в PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\export-prices.ps1 -InputPath "C:\Users\droid\Downloads\Цены.xlsx" -OutputPath .\prices-export.json
```

Excel и дополнительные модули не нужны. По умолчанию читается первый лист; другой можно выбрать параметром `-SheetName "Лист1"`. Каталог назначения должен существовать. Исходный Excel не изменяется. Скрипт сохранён в UTF-8 с BOM для Windows PowerShell 5.1.

Заголовки должны находиться в первой строке. Скрипт ищет столбцы по названиям, поэтому их можно переставлять. Строки повторителя берутся из всех пар `Название[n]` / `Значение[n]`. Пустые пары пропускаются, неполные вызывают ошибку с номером строки. Несколько услуг в столбце «Услуга» разделяются запятыми. В самих названиях услуг запятые при таком формате не допускаются; наименование позиции может содержать запятую.

В JSON сохраняются заголовок записи, названия связанных услуг, значения ACF, номер исходной строки и стабильный ключ. Цены и проценты — числа без единиц. Формулы читаются по сохранённому результату: после изменения формул пересчитайте и сохраните книгу в Excel. Если строка некорректна, итоговый файл не перезаписывается.

`prices-export.json` уже выгружен из предоставленного файла. Это данные записей, а не конфигурация ACF: загрузить его через «Импорт групп полей» нельзя.

## Импорт записей в WordPress

1. Импортируйте `acf-prices-import.json` через ACF. Типы записей `prices` и `services` должны уже существовать.
2. Создайте услуги с **точно такими же названиями**, как в Excel. Если услуга отсутствует или одинаковое название имеют несколько записей, импорт остановится до записи данных. Новые услуги автоматически не создаются.
3. Скопируйте JSON, `scripts/import-prices.php` и `scripts/prices-import-core.php` на сервер, сохранив оба PHP-файла в одной папке. Скрипт самостоятельный: подключать его в тему не нужно.
4. В каталоге WordPress выполните проверку без записи:

```sh
wp eval-file scripts/import-prices.php prices-export.json --use-include
```

5. Для записи выполните:

```sh
wp eval-file scripts/import-prices.php prices-export.json apply --use-include
```

Команда использует позиционные аргументы [`wp eval-file`](https://developer.wordpress.org/cli/commands/eval-file/). Проверка всех записей и связей происходит до начала записи. Новые цены создаются **черновиками**; у обновляемых сохраняется статус публикации. Скрипт записывает ACF через ключи полей, включая повторитель и связи с ID услуг.

Повторный импорт обновляет записи, созданные этим импортёром: ключ хранится в `_shina_price_source_key` и определяется наименованием и набором услуг. Изменение суммы или перестановка строк не создают дубли; изменение названия позиции или её услуг создаёт новую запись. Цены, ранее созданные вручную без этого ключа, автоматически не сопоставляются. Позиции, удалённые из Excel, не удаляются из WordPress. Ошибка базы во время записи может оставить частично выполненный импорт; исправьте причину и повторите запуск — записанные позиции будут обновлены по ключам.

На текущем компьютере проверен экспорт Excel; импорт в WordPress не запускался. Он требует WP-CLI и активного ACF на целевом сайте.

## Импорт через страницу без WP-CLI

1. Создайте папку `wp-content/plugins/shina-prices-import/` на сайте.
2. Скопируйте туда `scripts/prices-import-page.php` и `scripts/prices-import-core.php`.
3. Активируйте плагин «Импорт цен из Excel» в админке.
4. На обычной странице добавьте блок «Шорткод» с `[shina_prices_import]`. Альтернативно откройте «Инструменты → Импорт цен» в админке — форма та же.
5. Войдите как администратор, выберите `prices-export.json` и нажмите «Проверить без импорта». Для импорта выберите файл повторно и нажмите «Импортировать цены».

Форма принимает JSON, выгруженный PowerShell-скриптом, а не сам Excel. Доступ ограничен правом `manage_options`; каждый POST проверяется nonce. Загруженный файл читается из временного каталога PHP и не сохраняется в медиабиблиотеку. После использования плагин можно отключить и удалить; цены останутся в базе. Не кешируйте страницу с формой импорта.

Если WP-CLI сообщает `Composer dependencies require PHP >= 8.3.0` из Contact Form 7, ошибка происходит при загрузке WordPress до импортёра. CLI и сайт могут использовать разные версии PHP: переключите CLI на PHP 8.3+ либо используйте форму в браузере, если сайт уже работает на подходящей версии. Шорткод не исправляет несовместимую версию PHP самого сайта.
