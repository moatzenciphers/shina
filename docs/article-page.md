# Детальная статья

Прототип: http://localhost:8080/article.html. На него ведёт первая карточка списка статей.

Порядок: `article-hero`, `article-content`, `related-service`, готовая `split-form`. Шапка и футер общие. Новые компоненты статьи используют общие цвета, типографику и сетку, отдельного CSS-бандла нет.

## Где менять данные

- `src/pages/data/article-page.js`: название, описание, рубрика, автор, дата, фоновое фото, пункты оглавления, связанная услуга и текст формы.
- `src/pages/content/seasonal-preparation.html`: обычный HTML основного текста. В примере p, h2/h3, ul/ol, table, blockquote, figure/img/figcaption и ссылки. Классы на тегах текста не нужны.
- `__ARTICLE_IMAGE__` в HTML заменяется URL изображения из импорта. Это локальный контент прототипа, а не механизм для обработки пользовательского HTML.
- Оценка времени чтения рассчитывается из текста, исходя из 180 слов в минуту. Автор указан как бренд, без выдуманного специалиста.

Hero использует доступное фото из проекта; дополнительные сведения и дата соответствуют первой примерной карточке. При публикации замените автора, даты и фото реальными данными. Оглавление и id заголовков должны совпадать.

Связанная услуга ведёт на seasonal.html. Кнопки калькулятора в общей форме сохраняют действие с service=seasonal. Отправка Pug-формы не подключена; при переносе используйте CF7 и его события.

## Будущий WordPress

HTML-блок рассчитан на стандартный контент записи (`the_content()`), основные данные — на поля записи и рубрики. Подготовлены WP-шаблоны и поля для записи/связанной услуги/формы: инструкция `docs/wordpress-articles.md`. Другие карточки Pug-списка пока остаются с href="#".

Общие рекомендации об осмотре после хранения сверены с https://continentaltire.com/news/seven-tips-storing-tires. Статья не задаёт сроки обязательной замены по закону, нормы остаточного протектора и инструкции самостоятельного шиномонтажа.
