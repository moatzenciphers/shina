# Отзывы, работы и контакты

## Основа и принятые решения

Проверены изменения до `23fbb6b`: готовы каталог и страницы услуг, статьи (обычные записи в рубрике articles), общие Flexible Content, меню Walker и общие ресурсы. У новых разделов не было собственных шаблонов.

Подтверждено владельцем: только выезд, телефон +7 (499) 648-19-90; контактные данные WordPress брать из настроек. «Работы» — фотогалерея. Отзывы — существующие записи, без внешних площадок, формы добавления и кнопки публикации отзыва. Новые композиции разрешены.

## Локальная версия

- `reviews.html`: список с полным текстом. Публичный прототип по умолчанию пустой: новые отзывы не выдумываются.
- `works.html`: галерея. По умолчанию пуста; иллюстрации из проекта не выдаются за выполненные заказы.
- `contacts.html`: подтверждённый телефон, выездной формат, Москва и МО, карта с точками мастеров из общей конфигурации, масштаб и геолокация. Адрес офиса не выводится.
- Общие шапка, футер, мобильные кнопки и калькулятор сохранены. Шрифты, цвета и боковые поля существующего сайта. Компонентные стили входят в общий main.scss.

## WordPress

1. Если CPT reviews уже имеет архив, используется `archive-reviews.php` (9 записей на страницу). В меню выбрать этот архив. Иначе создать обычную страницу и назначить шаблон «Отзывы клиентов» (`page-reviews.php`). Не создавать два публичных списка с одинаковым содержимым.
2. Создать страницу «Фотографии работ» (рекомендуемый slug `vyezdy`) с шаблоном «Фотографии работ» (`page-works.php`). Выбрать изображения в ACF `works_images`; выбор сохраняет порядок. Пустой выбор — изображения медиабиблиотеки с `shina_photo_is_active=1`. Только реальные фотографии.
3. Создать «Контакты» с шаблоном «Контакты» (`page-contacts.php`). Телефон `shina_phone`, график `shina_work_schedule`, email `shina_email`, дополнительные ссылки `shina_contact_links`, реквизиты `shina_legal_details` берутся с общей страницы настроек `main-option`. Email, ссылки и реквизиты не показываются, пока не заполнены. Карта показывает зону и мастеров, не адрес приёма клиентов.
4. Поля `support_title` (по умолчанию стандартный заголовок страницы), `support_intro` и `support_form_shortcode` необязательны. Вступление не заполняется автоматически. Форма появляется только по шорткоду уже существующей CF7-формы.
5. Для архива отзывов поля находятся в «Отзывы → Настройки страницы», `post_id=reviews-archive`. На обычных страницах — в редактировании страницы.
6. Новые ACF-группы автоматически регистрируются из `inc/acf-support-pages.json`. Отдельный экспорт: `acf-support-pages-import.json`; общий — `acf-landing-import.json`. Существующие ключи сохраняются. Обновление: `node generate-landing-acf.cjs --write`.
7. Внешний вид пагинации общий, переходы — настоящие ссылки, записи отдаются сервером. Отзывы без флага активности считаются активными, явно выключенные скрыты. Главная по-прежнему показывает максимум 9 отзывов.
8. Заголовок/текст/автор/оценка/дата/фото берутся из существующего reviews и его ACF; услуга — review_service с прежним fallback. Карточки целиком показывают текст; миниатюры квадратные, открываются в GLightbox. У галереи 12 фото на страницу; подпись берётся из shina_photo_label и caption вложения.

## SEO и публикация

- У каждого раздела один H1, хлебные крошки, самостоятельный title и description в прототипе. WordPress title/description/canonical остаются под управлением существующей SEO-системы (в сохранённом crawl был Yoast); не добавлены конкурирующие метатеги и JSON-LD.
- Нет вымышленных оценок, суммарных чисел, локальных адресов, подписей заказов и отзывов. Нет искусственного текста ради объёма.
- Пагинация доступна без JavaScript, изображение имеет размеры/srcset средствами WordPress, lazy loading для галереи. Содержимое отзывов доступно в HTML полностью.
- Перед публикацией заполнить реальные данные/фотографии, назначить шаблоны, обновить меню через админку и проверить метаданные и индексацию уже на действующем сайте.
- Прямой URL публичного сайта, текущая БД, SEO-плагин и реальные записи в этой сессии не проверялись; выводы о коде не являются аудитом продакшена. WP-ядро, БД и опубликованные страницы не изменялись.
