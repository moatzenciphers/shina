# Перенос лендинга в WordPress

Если в редакторе ACF макет Flexible Content отображается пустым, повторно импортируйте `acf-landing-import.json` через **ACF → Инструменты → Импорт**. В исправленном файле `layouts` имеет формат объекта с ключами макетов, как в экспорте ACF этого проекта; существующая группа с тем же ключом обновится. После импорта откройте группу «Лендинг: блоки главной» и проверьте вложенные поля макета.

## ACF

Импортируйте [acf-landing-import.json](acf-landing-import.json) через **ACF → Инструменты → Импорт групп полей**. Файл добавляет гибкое содержимое «Блоки страницы» для статической главной страницы и поля цены для записей `services`.

В **Настройки → Чтение** назначьте статическую главную страницу. На её экране редактирования добавьте блоки в нужном порядке: первый экран, преимущества, шаги, услуги, ряды с фото, отзывы, карта, фото выездов, FAQ, форма помощи. Импорт группы полей создаёт структуру редактора, но не заполняет страницу контентом. Для повторяющихся текстовых блоков шаблон содержит стартовый текст; изображения и CF7-шорткоды укажите в админке. Для первого экрана поле «Фоновое изображение для мобильных устройств» необязательно: при его заполнении до 850 px выводится отдельное фото через `picture`, а без него используется основное изображение. После обновления кода повторно импортируйте `acf-landing-import.json`, чтобы поле появилось в редакторе.

Для расчёта времени прибытия импортируйте обновлённый [acf-calculator-settings-import.json](acf-calculator-settings-import.json) и заполните в настройках калькулятора поле «Ключ OpenRouteService для расчёта времени». Вместо поля ключ можно задать константой `SHINA_OPENROUTESERVICE_API_KEY` в `wp-config.php` или переменной окружения сервера `OPENROUTESERVICE_API_KEY`. На главной странице и калькулятор, и форма карты используют один ключ, координаты мастеров и алгоритм расчёта. Координаты мастеров задаются в карте настроек калькулятора; импорт ACF больше не создаёт демонстрационные метки. Если сохранилась старая демонстрационная карта из 30 точек, тема попробует восстановить прежние настроенные координаты, а при их отсутствии оставит карту без меток мастеров. Без ключа показывается настроенное запасное время с пометкой о недоступности маршрута.

Существующие [acf-reviews-import.json](acf-reviews-import.json) и [acf-media-library-photos-import.json](acf-media-library-photos-import.json) используются без изменений. У услуги заполните «Текст карточки на главной» и «Цена от, ₽». Если текст карточки пуст, используется краткое описание записи; без цены карточка остаётся без выдуманного значения. После обновления кода повторно импортируйте `acf-landing-import.json`, чтобы новое поле появилось в редакторе. Ссылки на все услуги и отзывы берутся из архивов соответствующих типов записей. Для фото выездов создайте страницу со slug `vyezdy`, если нужна ссылка «Посмотреть больше выездов».

## Contact Form 7

Создайте четыре формы, вставьте в них разметку файлов ниже и укажите шорткоды созданных форм в полях главной страницы:

| Форма | Разметка CF7 | Поле ACF |
| --- | --- | --- |
| Быстрый вызов | [cf7-quick-call.txt](cf7-quick-call.txt) | Шорткод CF7 быстрого вызова |
| Проверка адреса | [cf7-map-panel.txt](cf7-map-panel.txt) | В блоке карты |
| Помощь | [cf7-help-form.txt](cf7-help-form.txt) | В блоке формы помощи |
| Подтверждение калькулятора | [cf7-calculator.txt](cf7-calculator.txt) | Шорткод CF7 подтверждения калькулятора |

Проверьте вкладку «Письмо» каждой формы: используйте её реальные mail-теги, например `[phone]`, `[address]`, `[details]`, а для карты также `[callout_price]` и `[arrival_time]`. Отправку и результат обрабатывает CF7; JS только проверяет адрес и заполняет расчётные поля.

## Шаблон и ресурсы

`front-page.php` обходит ACF Flexible Content и подключает соответствующие `template-parts/landing-*.php`. Логика общих элементов находится в `inc/landing.php`. Файлы `header.php` и `footer.php` оставлены как есть.

Собранные `js/landing.css`, `js/landing.js` и фоны в `img/` уже размещены в теме. Раскрытие длинных отзывов входит в собранный `js/landing.js`: короткие отзывы остаются без кнопки, длинные открываются целиком в диалоге. При изменении исходников выполните `npm run build`, затем скопируйте новые `dist/css/main.*.css` в `js/landing.css`, `dist/js/main.*.js` в `js/landing.js` и нужные изображения из `dist/img/` в `img/` темы. `generate-landing-acf.cjs` обновляет JSON импорта, а `generate-wp-calculator.cjs` выводит HTML калькулятора из собранного Pug-шаблона для part-файла.

Текущие `header.php` и `footer.php` относятся к старому интерфейсу приложения. Их адаптация под новую шапку и футер лендинга остаётся отдельной задачей по вашему указанию.
