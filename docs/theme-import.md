# Перенос актуальной темы

Дата: 12 ноября 2026 года.

## Что является актуальной версией

Владелец передал тему в корневой папке `edemchinim/`. Она сохранена как исходный снимок без изменений. Рабочая тема — `Wordpress/wp-content/themes/edemchinim/`.

Перенесены все 97 файлов снимка: классы, автозагрузка, шаблоны, Walker, интеграции CF7/Telegram, REST API, ресурсы, изображения и проверки. Из рабочей темы удалены 54 отсутствующих в снимке файла старой реализации. История старой темы остаётся в Git; дополнительная резервная копия сохранена в `/tmp` при переносе. WordPress, плагины, база, формы и настройки действующего сайта не изменялись.

## Структура и дальнейшие изменения

- `functions.php` → `inc/autoload.php` → `Edemchinim\Bootstrap`.
- `inc/Theme/`, `inc/Content/`, `inc/Calculator/`, `inc/Rest/`, `inc/Support/` — текущие классы темы.
- `template-parts/blocks/` — ACF-блоки; имена layouts и сохранённые ключи полей не переименовывать.
- `template-parts/layout/` — header/footer, `template-parts/forms/` — общая форма, `template-parts/pages/support.php` — отзывы/работы/контакты.
- `css/landing.css`, `js/landing.js` — текущие общие ресурсы. `js/calculator.js` — калькулятор. Подключение в `inc/Theme/Assets.php`.
- `src/` и `dist/` остаются прежними фронтенд-прототипами. Их сборка не синхронизирует изменения актуальной темы и не должна перезаписывать её ресурсы.
- Экспорты ACF в корне сохранены как отдельные инструменты. Обычный запуск генератора больше не добавляет старые JSON в рабочую тему. `--install-theme-fields` нужен только при намеренном восстановлении прежних локальных определений; при этой миграции не использовался.

## Поправки при интеграции

1. В переданном `inc/Calculator/Config.php` использовались `TEMPLATE = 'calculator.php'` и `is_page(self::TEMPLATE)`, хотя реальный файл — `page-calculator.php`. Это ломало распознавание страницы и подключение калькулятора после переименования. В рабочей копии исправлено на `page-calculator.php` и `is_page_template()`. Исходный снимок не изменён.
2. Сохранён существующий `img/back.png`: его нет в снимке, но актуальный блок hero обращается к нему, если фон не задан в ACF. Это прежнее изображение проекта, не новая иллюстрация.

3. В `style.css` добавлен обязательный заголовок темы WordPress (`Theme Name`, версия, text domain). В переданном файле его не было; CSS-правила не изменены.

Все остальные файлы снимка перенесены без изменения содержимого. Ресурсы не пересобирались из прототипов.

## Проверки

Из `Wordpress/wp-content/themes/edemchinim/`:

```bash
php tests/theme-contract.php
php tests/theme-contract.php --without-acf
php tests/template-render-check.php
php tests/telegram-test.php
```

Проверки используют заглушки: не запускают реальную миграцию данных, не отправляют заявки и не обращаются к рабочей БД. В исходном снимке первые проверки падали на распознавании калькулятора. После описанной поправки проходят: 24 группы совместимости, 35 контрактов шаблонов, 70 перенесённых методов с ACF и без него, 76 сценариев рендера, проверки изоляции Telegram/почты.

PHP-файлы также проверены на синтаксис. Установка темы на действующий сайт и проверка его БД в этот перенос не входят.
