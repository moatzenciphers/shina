# Как подготовить колёса к сезонной замене

По запросу владельца создана детальная страница для первого материала демонстрационного списка. Hero с метаданными, обычный HTML-контент и оглавление, связанная сезонная услуга и существующая форма. Из списка настроена ссылка на article.html.

Контент помогает описать комплект, подготовить крепёж и согласовать состав обслуживания. Источник для общего утверждения об осмотре шин после хранения: https://continentaltire.com/news/seven-tips-storing-tires, поиск 21 октября 2026. Нормы закона, числа о безопасности, стоимость и гарантированные результаты не добавлялись. Источник поддерживает общий совет, но не подтверждает оснащение компании.

Текст в HTML-файле — единственный источник основного содержимого. Метаданные и связь услуги в data/article-page.js. Время чтения вычислено по количеству слов; дата соответствует демо-карточке, автор указан брендом без имени выдуманного эксперта. WordPress не публиковался; памятка docs/article-page.md.

Подготовлен отдельный WP single-article.php, подключаемый только для post рубрики articles и её потомков. На WordPress источник — стандартный контент записи, ACF содержит лишь метаданные/связь/форму; демонстрационный HTML автоматически не импортируется. Установка docs/wordpress-articles.md, импорт acf-articles-import.json. Оглавление по H2, неопубликованная связанная услуга скрывается, пароль записи учитывается. PHP runtime здесь не проверен.
