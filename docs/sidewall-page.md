# Страница ремонта боковых порезов

Локальный предпросмотр при запущенном dev-сервере: http://localhost:8080/sidewall.html. После сборки — `dist/sidewall.html`. На действующем WordPress ничего не публиковалось.

Использованы десять существующих блоков в том же порядке, что на других страницах услуг. Новые композиции и стили не создавались; SCSS-правки владельца сохранены. В общем меню и каталоге добавлены ссылки на страницу. У готового блока шагов добавлена возможность брать подпись кнопки из данных страницы.

## Где редактировать

- `src/pages/data/sidewall-page.js`: SEO-поля, hero, преимущества, две колонки, тексты прайса, шаги, фото-ряды, FAQ и форма.
- `src/pages/data/sidewall-prices.js`: таблица читает записи услуги «Ремонт боковых порезов» из `prices-export.json`. Все суммы выводятся с «от». Вне таблицы числовые цены не повторяются.
- `src/pages/sidewall.pug`: порядок готовых секций.

По решению владельца CTA открывают **общий калькулятор**: `calculator.html`, без `service=puncture` и других подмен. Отдельный расчёт боковых порезов не добавлялся. При переносе на WordPress сохраните общий URL для этой страницы, пока соответствующий тариф не будет поддержан калькулятором.

## Что заменить или уточнить

1. Hero: замените `hero.image` на реальный кадр из `src/img`. Сейчас `sidewall-placeholder.svg` служит фоновым изображением. Желательно свободное место слева под текст.
2. Два ряда `mediaRows.rows`: задайте `image` и `alt` для осмотра боковины и проверки/замены колеса. Поле `photo` используется только для подписи заглушки.
3. Выберите реальные отзывы по теме. Общий массив отзывов не менялся; на странице стоят прежние временные материалы.
4. Подтвердите фактический состав услуги, допустимые операции, условия гарантии и стоимость осмотра, если ремонт не выполняется. Тексты не обещают устранение повреждения корда или вздутия.
5. На WordPress перенесите контент в существующие ACF-макеты, выберите опубликованные цены в `services_prices`, FAQ — из записей `faq`, формы — шорткодами CF7. Новые ACF-компоненты не нужны.
6. Для окончательного адреса сохраните уже существующий URL услуги, если он есть. Прежний путь карточки проекта — `/uslugi/remont-bokovyh-porezov/`; фактическая публикация по этому адресу не проверялась. Canonical и sitemap задаются для выбранного адреса на WordPress.

## Предложение по содержанию

Для этой услуги полезнее реальные фотографии дефектов с коротким пояснением решения мастера: осмотр, допустимое обслуживание либо замена. Это можно разместить в существующем `media-rows`; отдельный блок создавать не требуется. До получения материалов оставлены заглушки. Не выдавайте иллюстрацию за реальный отчёт о выполненном заказе.

Предложенная композиция двух колонок уже использует `columns-list`: слева критерии осмотра, справа признаки необходимости замены. Так посетитель видит ограничения услуги до прайса. Подробные инструкции по самостоятельному ремонту боковины не размещаются.
