# Общая страница цен

Действующий адрес — `/prices/`. Файл актуальной темы: `Wordpress/wp-content/themes/edemchinim/page-prices.php`.

Для существующей страницы со slug `prices` WordPress автоматически выберет этот файл. Для другого slug доступен шаблон «Все цены по услугам». Создавать другую страницу или менять текущий адрес не требуется.

## Данные

- H1 берётся из названия страницы; необязательное вступление — из её стандартного редактора. Новые поля для текста или сумм не нужны.
- `Edemchinim\Content\Prices::groups()` получает опубликованные services по menu_order/title. Тарифы берутся только из `services_prices`, в порядке связи ACF, только опубликованные prices. Поддерживаются ID и WP_Post.
- Внутри услуги основные тарифы и доплаты разделены по `price_additional`. Суммы, «от», рубли за штуку, проценты и колонки таблиц выводятся существующим `Prices::renderTable()`. Цены не копируются в разметку и не берутся из устаревшей выгрузки.
- Услуги без связанных опубликованных тарифов не показываются. Непривязанные цены не назначаются услугам автоматически. Если ни одной группы нет, выводится пустое состояние.
- Ссылка каждой группы ведёт на услугу. Общая кнопка расчёта ведёт в существующий калькулятор. Шапка, футер, телефон и формы остаются общими и используют текущие настройки.

## Компоновка и стили

На десктопе оглавление закрепляется слева; справа выводятся все группы без пагинации. До 850 px оглавление располагается сверху в две колонки. У секций есть scroll-margin с учётом шапки. Широкие таблицы прокручиваются внутри своей области и доступны с клавиатуры.

Исходник дополнительного SCSS: `src/scss/components/_prices-page.scss`. Он отдельно скомпилирован и добавлен в конец общего `css/landing.css` между маркерами `prices-page:start/end`, без перезаписи текущих стилей темы. Отдельный CSS или JS для страницы не подключается; ресурсы старых прототипов не пересобирались.

## Проверка

```bash
cd Wordpress/wp-content/themes/edemchinim
php tests/prices-page.php
php tests/theme-contract.php
php tests/theme-contract.php --without-acf
php tests/template-render-check.php
```

Проверка новой страницы использует изолированные данные, не создаёт цены и услуги в WordPress. Подтверждает связи, опубликованные записи, варианты ACF, разделение доплат, форматирование, якоря и пустое состояние. Для визуальной проверки: `php tests/prices-page.php --render > /tmp/prices.html` (тестовая разметка, не публичное наполнение).

Действующая БД в этой сессии не менялась. Перед публикацией достаточно обновить файлы темы; цены редактируются в существующих записях и связях услуг.
