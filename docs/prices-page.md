# Общая страница цен

Действующий адрес — `/prices/`. Файл актуальной темы: `Wordpress/wp-content/themes/edemchinim/page-prices.php`.

Для существующей страницы со slug `prices` WordPress автоматически выберет этот файл. Для другого slug доступен шаблон «Все цены по услугам». Создавать другую страницу или менять текущий адрес не требуется.

## Данные

- H1 берётся из названия страницы; необязательное вступление — из её стандартного редактора. Новые поля для текста или сумм не нужны.
- `Edemchinim\Content\Prices::groups()` получает опубликованные services по menu_order/title. Тарифы берутся только из `services_prices`, в порядке связи ACF, только опубликованные prices. Поддерживаются ID и WP_Post.
- Внутри услуги основные тарифы и доплаты разделены по `price_additional`. Суммы, «от», рубли за штуку, проценты и колонки таблиц выводятся существующим `Prices::renderTable()`. Цены не копируются в разметку и не берутся из устаревшей выгрузки.
- Услуги без связанных опубликованных тарифов не показываются. Непривязанные цены не назначаются услугам автоматически. Если ни одной группы нет, выводится пустое состояние.
- Ссылка каждой группы ведёт на услугу. В конце страницы используется общий блок split-form с действующей формой CF7 «Форма в CTA». При наличии support_form_shortcode у страницы он заменяет стандартный шорткод. Новую форму и обработчики отправки создавать не нужно. Шапка, футер, телефон и формы остаются общими и используют текущие настройки.

## Компоновка и стили

На десктопе оглавление закрепляется слева, справа расположены свёрнутые details/summary по услугам. До 850 px оглавление располагается сверху в две колонки. Любой блок раскрывается мышью или клавиатурой; несколько блоков могут оставаться открытыми для сравнения. Раскрытие/закрытие высоты выполняется WAAPI за 240 мс с cubic-bezier(.23,1,.32,1), повторный клик разворачивает движение с текущего размера. При reduced motion переключение мгновенное. Открытый прайс оформлен отдельной фоновой поверхностью с полями 24 px (16 px на мобильном), спокойными заголовками таблицы и ссылкой услуги справа внизу.

Якорь оглавления указывает на details услуги. Модуль src/js/prices-page.js сначала раскрывает нужную группу, затем прокручивает к заголовку и переводит фокус на summary. Плавность задаётся scroll-behavior в SCSS, отступ под шапку — scroll-margin-top; prefers-reduced-motion отключает плавность. Модуль входит в общий src/js/index.js; отдельный скрипт страницы и библиотеки не подключаются. Широкие таблицы прокручиваются внутри своей области и доступны с клавиатуры. Общий split-form размещается после прайса, внутри main, с собственными стандартными полями секции.

Стили страницы находятся в `src/scss/components/_prices-page.scss` и подключены через `@use "components/prices-page"` в `src/scss/main.scss`. Они входят в общую сборку `npm run build`, результат — `dist/css/main.*.css`. Ручной блок в `css/landing.css` удалён; скомпилированные CSS-файлы не редактировать. PHP-шаблон и существующие ресурсы актуальной темы сохранены.

## Проверка

```bash
cd Wordpress/wp-content/themes/edemchinim
php tests/prices-page.php
php tests/theme-contract.php
php tests/theme-contract.php --without-acf
php tests/template-render-check.php
```

Проверка новой страницы использует изолированные данные, не создаёт цены и услуги в WordPress. Подтверждает связи, опубликованные записи, варианты ACF, разделение доплат, форматирование, якоря и пустое состояние. Для визуальной проверки: `php tests/prices-page.php --render > /tmp/prices.html` (тестовая разметка, не публичное наполнение).

Действующая БД в этой сессии не менялась. Перед публикацией достаточно обновить файлы темы; цены редактируются в существующих записях и связях услуг.
