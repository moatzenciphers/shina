# Ремонт проколов шин

Предпросмотр при запущенном dev-сервере: http://localhost:8080/puncture.html. Страница также собирается в `dist/puncture.html`. Это исходный прототип; публикация на WordPress не выполнялась.

Использованы десять готовых блоков: hero, features-grid, columns-list, price-table, steps-grid, media-rows, slider-grid, map-panel, accordion-grid, split-form. Общие шапка, футер, сетка и стили сохранены. Новые типы блоков не добавлялись. Ссылки «Ремонт проколов» в общем меню и карточке главной ведут на новый прототип.

## Где менять контент

| Данные | Файл |
| --- | --- |
| Title, description, H1, оффер, преимущества | `src/pages/data/puncture-page.js`: meta, hero, features |
| Подготовка к выезду и шаги | Там же: columnsList, steps |
| Основная таблица | `src/pages/data/puncture-prices.js` читает `prices-export.json`, услуга «Ремонт проколов» |
| Пояснения к прайсу | `src/pages/data/puncture-page.js`: prices |
| Два ряда с фотографиями | Там же: mediaRows |
| Вопросы и форма | Там же: faq, form |
| Порядок секций | `src/pages/puncture.pug` |

Оба варианта ремонта и суммы по диаметрам взяты из предоставленной выгрузки Excel. Названия сохранены: «Временный ремонт» и «Полноценный ремонт с гарантией». Выезд оплачивается отдельно. Его сумма и время зависят от адреса и расчёта существующего приложения; обещание фиксированной подачи в тексты услуги не добавлено.

Калькулятор открывается с `service=puncture` и пока считает существующий тариф временного ремонта. Выбор полноценного ремонта в нём не добавлялся. До внедрения такого выбора оператор должен отдельно согласовывать выбранный вариант. Уточните состав двух вариантов, единицу цены, срок и условия гарантии: они не придуманы в текстах.

## Фото и отзывы

1. Hero: добавьте фото автомобиля и мастера в `src/img`, замените `hero.image`. Сейчас используется `puncture-placeholder.svg`, оформленный фоном как на главной. Для текста желательно оставить свободную левую часть кадра.
2. `mediaRows.rows[0]`: добавьте `image: require('../../img/имя-файла.jpg')` и `alt` для осмотра колеса.
3. `mediaRows.rows[1]`: аналогично задайте фото ремонта или проверки результата. Поле `photo` служит подписью заглушки и после добавления image не отображается.
4. Текущие отзывы используются временно по прежнему указанию владельца. Общий массив `src/pages/data/reviews.js` не менялся; перед публикацией выберите реальные отзывы о ремонте проколов.

## Перенос на WordPress

- Используйте существующие макеты `blocks`, без новых PHP-компонентов или новых групп ACF.
- В hero выберите вариант «Услуга»; перенесите тексты из данных страницы, фото задайте из медиабиблиотеки.
- В поле записи услуги `services_prices` выберите нужные позиции прайса. Макет таблицы содержит только eyebrow, title, description и group-note; суммы и колонки читаются из связанных `prices`. У текущих позиций ремонта проколов признак «Дополнительная» выключен, поэтому группа «Доплаты» не нужна.
- Создайте или выберите записи `faq`, перенесите в них подготовленные вопросы и ответы; отзывы выберите из `reviews`.
- Формы быстрого вызова, проверки адреса и помощи подключите через CF7. Pug-формы остаются прототипами. Проверьте передачу услуги обработчику заявок.
- Текущий калькулятор принимает ключ `puncture`. После недавнего изменения WordPress передаёт в `service` слаг записи: при слаге вроде `remont-prokolov` нужно отдельно сопоставить его ключу `puncture` в конфигурации/обработчике калькулятора. Этот прототип не меняет существующую логику расчёта.
- Сохраните существующий URL услуги, если она уже опубликована. Для новой записи возможен адрес `/uslugi/remont-prokola/`, который ранее указан в карточке проекта. Это предлагаемый путь, а не проверенный опубликованный адрес. Окончательный canonical и sitemap настройте через текущий SEO-плагин после выбора URL.

SEO-тексты ориентированы на ремонт прокола шины с выездом в Москве и МО: стоимость, возможность ремонта, осмотр, организация приезда и FAQ. Цифры частотности и обещания позиций в поиске не использовались. Источники и ограничения исследования записаны в `.seoagent/content/puncture.md`.
